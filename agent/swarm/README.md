## Что это

Идея Петра: рой букашек-блогеров. Движок (17.0.0) оценивает каждого автора
строго изолированно (BREAKING §1), рой — юзерспейс: трек автора = сыгранные/
прибыльные МЕСЯЦЫ, допуск months≥3 ∧ rate≥0.5, эксплуатация = последняя
рекомендация каждого допущенного в окне holdMinutes, вес = wins, W_long vs
W_short. Канон: [_reference/PLAN-petr.md](_reference/PLAN-petr.md) (его план —
закон; наши контроли — аддитив РЯДОМ) + [_reference/BREAKING-simulator.md](_reference/BREAKING-simulator.md).
Утверждённый план сессии: `~/.claude/plans/immutable-honking-flask.md`.

   числа выживших + OOS калибровочного хвоста. Зафиксировать в `point.json`.
4. Этап 2: прогон `src/index.mjs` по 12 папкам (цикл по авторам, изолированные
   однобукашечные прогоны). Свечной кеш движка общий; для RAM-фидов помнить

6. Этап 4: `node tools/swarm_rank.mjs data/btc_2025 2025` → swarm.json.
7. Этап 6: `node tools/verify_verdicts.mjs data/ts-ideas.btc-2025.jsonl
