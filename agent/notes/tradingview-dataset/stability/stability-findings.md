# Устойчивость авторов через месяцы (№120→№121) — сигнала НЕТ, ветка закрыта

**Дата:** 23.07.2026 · дизайн: [../bigtune/author-stability-design.md](../bigtune/author-stability-design.md)
(критерии объявлены ДО прогона, не менялись) · раннер: [stability.mjs](stability.mjs) ·
движок 16.5.0, свечи локальные, фрикшн вшит (слиппедж + 2×fee).

**Наводка Петра:** «лучшие из лучших, которые есть в КАЖДОМ месяце; тупо работать
по ним окном; промежуточные точки закодить агентом». Реализовано дословно + три
объявленных контроля.

## Пайплайн

A) помесячные authorStats BTC 2022-01..2026-07 (55 мес, hit = close через 5 дней);
B) фильтр устойчивости: активен (≥3 идеи с исходом) во ВСЕХ K трейлинг-месяцах И
hitRate≥rate в ≥80% из них; 4 варианта K∈{4,6}×rate∈{0.55,0.60};
C) rolling-форвард: вайтлист месяца M только по [M−K..M−1] → Simulator.test на M,
фикс-выходы демо (стоп 5 / трейлинг 2 / лок 2.5 / 72ч), гейты выключены;
D) контроли: placebo×20 (те же авторы, та же активность, скилл ~ Binomial по
пул-рейту месяца, тот же фильтр) + always-long/short с профилем выживших.

**Критерий успеха (заранее):** медиана real > медианы placebo (знаковый p<0.05)
И > обоих направленческих бейзлайнов.

## Три факта, закрывающие ветку

1. **«Лучших из лучших в каждом месяце» в данных почти нет.** За 55 месяцев фильтр
   прошли ДВА автора, вайтлист никогда не превышал 1: BitCoinGuide (окна
   2024-12..2025-02) и InvestingScope (2025-05..07). Ровно масштаб «~1 счастливчик
   на пул», предсказанный дизайном для чистого монеточника (P≈0.3^K).
2. **Устойчивость = направление, не прогноз.** InvestingScope — пермабык
   (longShare окна 0.98–1.00): его форвард (+2.06% / +0.97%) СОВПАДАЕТ с
   always-long бейзлайном по построению — прогнозной ценности ноль. BitCoinGuide
   (longShare 0.64–0.67) в форварде −10.77% / −1.79% / −9.08% — хуже always-long
   в 2 из 3 месяцев, хуже always-short во всех трёх.
3. **Placebo проходит фильтр так же легко.** 85/280 плацебо-реплик (30%) дали
   непустой вайтлист при той же активности и случайном скилле — сам факт
   «стабилен K месяцев» ничего не доказывает. Спред плацебо-форвардов
   −30%…+8.6%; real от их медианы неотличим (p=0.69–1.0).

## Технический урок

Свечной дисковый кэш движка (`dump/data/candle/…`, JSON на каждую 1m-свечу)
на локальном RAM-фиде = ENOSPC: первый прогон умер на 26-м месяце, слой
контейнера ~10ГБ (bigtune, оказывается, оставил такой же — снесён при чистке
23.07, диск 78%→28%). Фикс: `PersistCandleAdapter.useDummy()` — заодно ускорил
фазу A с ~1 мин/мес до ~2 с/мес. Для будущих симуляторных прогонов — ставить всегда.
