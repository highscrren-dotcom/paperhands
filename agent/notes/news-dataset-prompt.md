## Целевая структура (скрин автора, ParserItem из pump-anomaly)

```ts
{ channel: string;            // = домен источника (kitco.com, cnbc.com, …)
  symbol: string;             // BTCUSDT/ETHUSDT/… (листинг Binance проверить)
  direction: "long"|"short";  // ← LLM-классификация новости
  ts: number;                 // = publishedDate, ms
  entryFromPrice?; entryToPrice?;  // у новостей НЕТ — опциональны, не выдумывать
  id?: string;                // = url (traceback)
}                              // targets/stoploss — allowed and ignored
```

## Конвейер (три скрипта в example/scripts/news_dataset/, данные в agent/notes/news-dataset/)

**1. news_collect.mjs** — сбор: Tavily по пулу-13 (advanced, `timeRange:"day"`
для ежедневного цикла), 4 clean-запроса классов ETF/FOMC/крах/регуляторка (из
tavily-queries.md A.3). БЕЗ порога score — берём ВСЕ результаты с валидной
датой (не 00:00 UTC). Дедуп по url против всего датасета. Выход:
`news-raw.jsonl` (url, domain, title, content, publishedDate, class, score).
Первый прогон — `timeRange:"week"`: ретро-затравка сразу за ~7 дней.
Бюджет: 4×2=8 кредитов/день (+2 у джекпот-монитора). Остаток аккаунта ~665.

**2. news_classify.mjs** — направление: каждый новый url → Ollama Cloud
(стек example уже настроен: см. logic/config и ai-healthcheck.mjs; модель как
у автора). Промпт строгий JSON: `{symbol: главный актив новости тикером или
null, direction: "long"|"short"|null (ожидаемое влияние НА ЦЕНУ актива),
confidence: 0..1}`. null-ы и не-листящиеся на Binance символы — в отсев
(вести счётчик отсева). Идемпотентно по url. Классификатор НЕ видит цену —
только текст (никакого look-ahead).

**3. news_dataset.mjs** — маппинг и валидация: собрать
`news-parser-items.jsonl` строго по структуре выше (channel=домен!),
+ сводка: постов на домен/символ/направление, глубина по датам.

**Автоматизация:** данные должны копиться БЕЗ Claude — дать владельцу готовую
крон-строку (раз в день, collect→classify→dataset конвейером, лог в
news-cron.log). Крон ставит владелец.

**Фит НЕ запускать** — pump-anomaly по датасету пойдёт отдельной сессией,
когда наберётся n≥10 на топ-домены и 2+ недели глубины (см. №71). Сейчас —
