## Что это значит (evidence-first)

- **Воспроизводимость подтверждена.** 3 из 3 завершённых прогонов совпали с README
  почти бит-в-бит (jan +8.548 vs +8.58; dec +2.395 vs +2.40; apr +67.851 vs +67.85).
  Детерминизм движка + честный учёт комиссии/слиппеджа работают как заявлено.

- **⚠️ Главный урок — apr_2026 (клон паттерна clarkkent5).** +67.85% выглядит
  прекрасно, НО: (а) это **бычий месяц** — buy&hold сам +15.19%; (б) всего **7 сделок,
  все прибыльные** — статистически ничтожная выборка (движок гейтит публикацию при
  <10 сигналов не зря); (в) наш наивный perTradeSharpe = 1.75 сильно завышен против
  **README Pooled Sharpe = 0.12** — именно их 0.12 честно отражает высокую дисперсию.
  Вывод: огромный % на нескольких удачных сделках в тренде — это **не доказанный эдж**.
  Ровно для этого и нужен наш OOS/walk-forward-гейт (`agent/tools/oos-gate.mjs`).

- **Naive Sharpe ≠ Pooled Sharpe.** Наш парсер даёт грубую оценку per-trade; для
  вердикта опираемся на неё осторожно, а «золотой» Sharpe берём из markdown-отчётов
  движка. Разрыв apr (1.75 vs 0.12) — напоминание не доверять высокому Sharpe на малой
  выборке.

- **buy&hold как бенчмарк** (которого нет в самом фреймворке): jan/dec/mar обыграли
  плоский/отрицательный hold; apr обыграл растущий hold (+52.66 п.п.), но на 7 сделках.
