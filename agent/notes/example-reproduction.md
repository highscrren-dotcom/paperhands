## Что это значит (evidence-first)

- **Воспроизводимость подтверждена.** Все 5 детерминированных стратегий совпали с README
  практически бит-в-бит. Движок детерминирован, комиссия/слиппедж учитываются как заявлено.
  «Clone → same prints» — правда.

- **⚠️ Урок №1 — apr_2026 (паттерн clarkkent5).** +67.85% — это **7 сделок, все прибыльные,
  в бычий месяц** (buy&hold сам +15.19%). README Pooled Sharpe = **0.12** (мизер) → дисперсия,
  а не эдж. Наш наивный perTradeSharpe тут завышен (1.75). Мораль: крупный % на малой выборке
  в тренде — не доказанный эдж. Для этого и нужен OOS-гейт.

- **⚠️ Урок №2 — oct_2021: «прибыльно» ≠ «хорошо».** Нейросеть сделала **+19.4%**, но
  buy&hold дал **+40.4%** — стратегия **проиграла ничегонеделанию на −21 п.п.** Без бенчмарка
  buy&hold этого не видно. Именно поэтому бенчмарк у нас всегда на виду (в самом фреймворке
  его в сводке нет).

- **Защитная ценность — apr_2024.** +0.63% выглядит ничтожно, но рынок в апреле-2024 упал
  на −11% — стратегия осталась в плюсе на падении (+11.6 п.п. к hold). Контекст решает.

- **naive Sharpe ненадёжен на малой выборке** (apr 1.75 vs Pooled 0.12) — для вердикта
  опираемся на него осторожно, «золотой» Sharpe берём из markdown-отчётов движка.
