## Что строить

**Новый репозиторий-директория `/home/s1dd1/dev/quant/news-service/`** (не внутри
paperhands!): python, FastAPI (swagger из коробки на /docs), Dockerfile +
docker-compose.yml. Структуру, стиль и зависимости диктует main.py автора —
наши правки поверх, не вместо.

Эндпоинты (минимум, уточнить по скелету):
- `GET /news?since=<ISO>&class=<etf|fomc|crash-rally|regulation>` — свежие
  новости (Tavily, наш пул-13 и clean-запросы из news_collect.mjs), JSON с
  url/domain/title/content/publishedDate/class/score + fetchedAt;
- `GET /health` — живость + остаток Tavily-кредитов если доступен;
- swagger на /docs (FastAPI даёт сам).

Правила переносим 1:1 из news_collect.mjs: только датированные (не 00:00Z),
дедуп по url (сервис ведёт свой журнал — sqlite или jsonl в volume), бюджет
Tavily ≤8 кредитов/день (лимитер в сервисе!), ключ из env (TAVILY_API_KEY),
в docker — через env_file, НЕ в образ.

**JS-сторона**: news_collect.mjs получает режим `--from-service http://localhost:<port>`
(дефолт остаётся прямой Tavily — миграция мягкая, крон не ломать). Итоговая
цель автора: js-конвейер тонкий (classify+dataset+sync), забор — в сервисе.

## Ограничения

- Скелет автора — канон: не переписывать его структуру под себя, достраивать.
- Боевой крон 09:40 НЕ ломать: сервис — параллельный путь до команды владельца.
- Tavily-бюджет общий ≤8 кр/день: пока сервис в обкатке, его вызовы Tavily
  выключены по умолчанию (env NEWS_SERVICE_DRY=1 → отдаёт из журнала).
- Docker: без --network=host, порт наружу только localhost; классификатор
  может блокировать docker-команды — тогда команды владельцу.
- Ничего не коммитить без «комить»; новый репо — git init, владелец решит
  про github.
- ОЗУ/токены: скелет и наш код маленькие, сырьё новостей в контекст не тащить.
