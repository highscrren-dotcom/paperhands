Похоже после успешного филла id сигнала не потребляется (как в реджект-ветке)
— стратегия переиздаёт тот же сигнал, слот не держит, движок покупает ещё.

Вторая деталь: брекеты легли неровно — TP-ордера у всех траншей, а стоп-лимит
только у последнего (0.201 SOL). Первые четыре транша на бирже без стопа
(софт-SL движка −1% работает, речь только про биржевую защиту от гэпа).

Ожидание: филл потребляет id так же, как терминальный реджект — одна позиция
на сигнал; и брекеты на каждый филл одинаковые (или один агрегатный OCO).

Логи и sync.jsonl вышлем по запросу. Воспроизведение: сигнал с фикс-id +
депозит на 2+ cost — второй филл прилетает через несколько минут после
первого.
