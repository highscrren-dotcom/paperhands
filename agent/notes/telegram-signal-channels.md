```
СИГНАЛ #TAO/USDT 🔑 Открыть ШОРТ в диапазоне $206.3 - $208.5 с плечом X25
🍒 Цели: 🔘 Закрыть по $204.6 🔘 ... (до 5 тейков) ❗️ СТОП ЛОСС: $215.4
```

≥2 цели + стоп. (У самого Yoda в ленту иногда попадают акции типа `#MU/USD` —
нужен фильтр «только `*USDT`».)

## Оговорки (честно, для решения владельца)

1. **Рыночный перекос:** сейчас (июль 2026, бычка) почти у ВСЕХ каналов сильный
   LONG-биас (часто 100% лонгов в последних 20 постах). Для аудита стратегии на
   истории это значит: только-лонг выборка сильно зависит от фазы рынка; для
   инвертной механики (торговля ПРОТИВ канала, DECISIONS №22) нужен период с шортами.
   Реальные шорты в выборке нашлись у **@crypto_fiuchersi** (RU, 688, но накрутка
   просмотров) и частично **@ccfindonesiantrader**.
2. **Глубина истории через t.me/s/ ограничена:** одна страница превью = только свежие
   посты. Каналы старые (fedrussian est.2017, kriptopro ~8 лет, universalcryptosignals
   4+ года), но чтобы вытащить 6 мес для аудита — нужен залогиненный TG-клиент/ingest
   с пагинацией `?before=<id>`, а не разовый фетч. Проверять глубину лучше уже
   механизмом ingest, которым парсите Yoda.
3. **Cherry-picking у всех:** публичные каналы почти поголовно показывают выигрыши и
   продают VIP. Значит публичная выборка сигналов может быть смещена (удаляют/не
   постят проигрыши) — для честного бэктеста считать это верхней оценкой, а не фактом.
4. **Мультиформатность:** у #1/#5/#3 в ленту попадают форекс/золото/акции — парсер
   ОБЯЗАН фильтровать пары по `*USDT` (как уже нужно для Yoda с `#MU/USD`).
5. **Не проверял глубоко:** субагенты отдавали часть полей как «н/д» (точные
   подписчики/старейшая дата) — где так, помечено. Ничего не додумано: в таблице
   только то, что реально видно на t.me/s/.
