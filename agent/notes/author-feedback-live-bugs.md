## 2. demo/ccxt: `timestamp: t.T` строкой роняет volume-anomaly 2.0.0

В `demo/ccxt/src/index.mjs` в `getAggregatedTrades` поле `timestamp: t.T`
берётся сырым. ccxt implicit-API (`publicGetAggTrades`) отдаёт ВСЕ скаляры
строками — проверено и на пине demo 4.5.24, и на 4.5.64:
`typeof t.T === "string"`. Строка доезжает до volume-anomaly 2.0.0 и валится
на валидации:

```
Error: timestamps must be finite numbers, got 1783601403565
```

(`Number.isFinite("1783601403565")` === false; валидатор —
`assertTimestamps`/`train`.)

**Фикс однострочный:** `timestamp: Number(t.T)` — p/q уже парсятся через
parseFloat, сырым остался только T. Наш рабочий шов с этим фиксом:
[../../example/scripts/pump_bench/lib.mjs](../../example/scripts/pump_bench/lib.mjs)
(`getAggregatedTrades`), репро — `getExecutedTradesSkew("BTCUSDT")` из demo как есть.
