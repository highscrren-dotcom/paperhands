# news_jul2026 — стенд движкового news-бэктеста (НЕ боевая стратегия)

**Что это.** Честный прогон новостных вердиктов из read-only зеркала
`news-audit`.verdicts (worker №85) через настоящий движок backtest-kit:
`getSignal(symbol, when)` фильтрует item'ы **строго `publishedAt <= when`**
(канон автора №76 — look-ahead невозможен по построению), запрос — дословная
копия `scripts/news_dataset/news_query.itemsFor()`.

**Правило стенда (вариант B, с 18.07 — совет автора «никогда не ставь TP/SL
фиксированным окном»).** Последний непотреблённый ok-item в окне 24ч до `when` →
сигнал `{position: direction, moonbag(TP +50% символич., жёсткий SL −1%),
timeout 24ч}`; выходы — trailing take (в профите отдали ≥1 п.п. от пика) и
peak staleness (пик ≥1% старше 240 мин), константы автора as-is. Один item =
один сигнал (дедуп по id/url в памяти прогона). Вариант A (фикс TP +1.5% /
SL −1%) — метрики в notes, сравнение там же.

## ОГОВОРКИ (читать до цифр)

- **n = 9 сигналов (BTCUSDT) — это ДИСПЕРСИЯ, НЕ ВЫВОД.** Ни одна метрика
  прогона не является свидетельством эджа.
- Фикс-параметры TP +1.5% / SL −1% / 24ч — заглушка: R/R = 1.5 **< 2 из
  доктрины** (сознательное упрощение); min TP 1% соблюдён номинально (1.5%).
- Доктрина «≥1 сигнал/день» не выполняется (9 сигналов на 11.5 дней).
- Две запиненных `promptVersion` (`v1` — история 06–13.07, `v2.1-vibe-2026-07-15`
  — с 16.07); внутри одного запроса версии не смешиваются.
- `includeBackfill=true`: в live затравка была бы доступна лишь с `fetchedAt`.
- Frame: `2026-07-06T00:00Z … 2026-07-17T12:00Z` (правая граница в прошлом на
  момент прогона); 24ч-таймаут последнего item'а (16.07 16:55Z) обрезан рамкой.
- Funding/спред движком не моделируются; комиссия+слиппедж 0.1%+0.1% включены.

## Режимы контрольных прогонов (env, урок TV-датасета №101)

`NEWS_STAND_MODE` = `real` (дефолт) | `placebo` | `long-only` | `invert`:

- **placebo** — те же item'ы/даты, направление = детерминированный бит
  FNV-1a(url + `NEWS_STAND_SEED`, дефолт `1`). Гонять НЕСКОЛЬКО сидов —
  один placebo-прогон сам по себе шум. Если real не лучше пучка placebo —
  «эджа» нет (Jensen-урок №101: даже случайное направление даёт ложный
  положительный μ).
- **long-only** — торгуются только long-вердикты (спот умеет только их).
- **invert** — все направления перевёрнуты (тест «шорты = анти-сигнал»,
  мотив: в прогоне №106 шорты 7/7 в минус).

Оговорка: слот позиции один, другие направления ⇒ другие длительности сделок ⇒
расписание последующих входов может слегка разойтись с real (свойство честного
движкового placebo). Сервер: `backtest.sh` пробрасывает обе переменные:
`NEWS_STAND_MODE=placebo NEWS_STAND_SEED=3 bash /opt/quant/bin/backtest.sh …`.
