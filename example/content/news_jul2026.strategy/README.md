# news_jul2026 — стенд движкового news-бэктеста (НЕ боевая стратегия)

**Что это.** Честный прогон новостных вердиктов из read-only зеркала
`news-audit`.verdicts (worker №85) через настоящий движок backtest-kit:
`getSignal(symbol, when)` фильтрует item'ы **строго `publishedAt <= when`**
(канон автора №76 — look-ahead невозможен по построению), запрос — дословная
копия `scripts/news_dataset/news_query.itemsFor()`.

**Правило стенда.** Последний непотреблённый ok-item в окне 24ч до `when` →
сигнал `{position: direction, TP +1.5%, SL −1%, timeout 24ч}`. Один item =
один сигнал (дедуп по id/url в памяти прогона).

## ОГОВОРКИ (читать до цифр)

- **n = 9 сигналов (BTCUSDT) — это ДИСПЕРСИЯ, НЕ ВЫВОД.** Ни одна метрика
  прогона не является свидетельством эджа.
- Фикс-параметры TP +1.5% / SL −1% / 24ч — заглушка: R/R = 1.5 **< 2 из
  доктрины** (сознательное упрощение); min TP 1% соблюдён номинально (1.5%).
- Доктрина «≥1 сигнал/день» не выполняется (9 сигналов на 11.5 дней).
- Две запиненных `promptVersion` (`v1` — история 06–13.07, `v2.1-vibe-2026-07-15`
  — с 16.07); внутри одного запроса версии не смешиваются.
- `includeBackfill=true`: в live затравка была бы доступна лишь с `fetchedAt`.
- Frame: `2026-07-06T00:00Z … 2026-07-17T12:00Z` (правая граница в прошлом на
  момент прогона); 24ч-таймаут последнего item'а (16.07 16:55Z) обрезан рамкой.
- Funding/спред движком не моделируются; комиссия+слиппедж 0.1%+0.1% включены.

## Воспроизведение

```bash
cd example
CC_WWWROOT_PORT=60054 npm start -- --backtest --symbol BTCUSDT --ui \
  ./content/news_jul2026.strategy/news_jul2026.strategy.ts

```

Требуется: локальный mongod с базой `news-audit` (зеркало №85, только чтение);
mongoose берётся из `../backtest-ollama-crontab` (прецедент news_query.mjs).
